# Politi MDT

Statisk browser-app til et Roblox RP politi-MDT.

## Filer

- `index.html`
- `styles.css`
- `script.js`

## Upload til GitHub

1. Opret et nyt repository på GitHub.
2. Upload alle filerne fra denne mappe.
3. Sørg for at `index.html` ligger i roden af projektet.

## Public med GitHub Pages

1. Gå ind på dit repository på GitHub.
2. Tryk på `Settings`.
3. Gå til `Pages`.
4. Under `Build and deployment` vælg:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/ (root)`
5. Tryk `Save`.

Efter lidt tid får du et link fra GitHub Pages, hvor din MDT ligger online.

## Note

Det her projekt er lavet som en ren frontend-prototype i HTML, CSS og JavaScript, så det kan hostes direkte på GitHub Pages uden ekstra setup.
